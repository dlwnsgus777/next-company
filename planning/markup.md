# 화면 기획 - 안 B: 칸반 보드형

> 지원 단계를 컬럼으로 배치해서 진행 상황을 한눈에 파악. 카드를 드래그해서 단계 이동.

---

## 화면 목록

| 번호 | 화면명 | 설명 |
|------|--------|------|
| B-1 | 메인 - 칸반 보드 | 기본 진입 화면, 지원 단계별 회사 카드 |
| B-2 | 메인 - 순위 보기 | 칸반과 토글 전환, 점수 기준 랭킹 |
| B-3 | 회사 상세 모달 | 카드 클릭 시 상세 정보 표시 |
| B-4 | 회사 추가 모달 | 새 회사 등록 폼 |
| B-5 | 회사 수정 모달 | 기존 회사 정보 편집 |
| B-6 | 평가 기준 설정 모달 | 평가 항목 및 가중치 관리 |

## B-6. 평가 기준 설정 모달

```
┌──────────────────────────────────────────────────────────────────┐
│  평가 기준 설정                                     [취소] [저장]│
├──────────────────────────────────────────────────────────────────┤
│  항목명              가중치 (%)                                   │
│                                                                  │
│  ≡  복지             [  35  ]                         [삭제]     │
│  ≡  집과의 거리      [  20  ]                         [삭제]     │
│  ≡  연봉             [  20  ]                         [삭제]     │
│  ≡  회사 규모        [  20  ]                         [삭제]     │
│  ≡  기술 스택        [   5  ]                         [삭제]     │
│                                                                  │
│  [+ 항목 추가]                             합계: 100%  ✓        │
├──────────────────────────────────────────────────────────────────┤
│  ⚠ 기준 변경 시 기존에 입력한 점수는 유지됩니다.                │
│     단, 삭제한 항목의 점수 데이터는 사라집니다.                  │
│                                                      [저장하기]  │
└──────────────────────────────────────────────────────────────────┘
```

**인터랙션:**
- `≡` 아이콘으로 항목 순서 드래그 변경
- 가중치 숫자 입력 시 합계 실시간 계산
- 합계가 100% 미달/초과 시 저장 버튼 비활성화 + 경고 표시
- `[+ 항목 추가]` → 빈 행 추가

## 페이지 & 라우팅

```
/                   ← 메인 (칸반 보드, 기본 진입)
/?view=rank         ← 순위 보기 (쿼리 파라미터로 뷰 전환)
```

모달은 URL 변경 없이 오버레이로 처리 (라우팅 불필요)
