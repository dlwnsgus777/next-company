# 이직 도우미 웹서비스 기획서

> 작성일: 2026-02-28

---

## 1. 서비스 개요

자신만의 기준으로 지원 회사들을 점수화하고, 지원 과정을 체계적으로 트래킹하는 이직 관리 도구.

---

## 2. 핵심 기능

### 2-1. 평가 기준 설정
- 사용자가 직접 평가 항목을 정의 (예: 복지, 연봉, 거리, 회사 규모, 기술 스택 등)
- 각 항목에 **가중치(비중)** 를 설정 (합계 100%)
- 항목은 추가/수정/삭제 가능

**예시 (스크린샷 기준):**
| 항목 | 가중치 |
|------|--------|
| 복지 | 35 |
| 집과의 거리 | 20 |
| 연봉 | 20 |
| 회사 규모 | 20 |
| 기술 스택 | 5 |

---

### 2-2. 회사 등록 및 관리
각 회사마다 아래 정보를 저장:

| 필드 | 설명 |
|------|------|
| 기업명 | 회사 이름 (부서/포지션 포함 가능) |
| 목표 회사 여부 | O (목표) / △ (고려 중) / X (비목표) |
| 채용공고 링크 | 원티드, 잡플래닛 등 URL |
| 채용 기한 | 지원 마감일 |
| 평가 항목별 실제 정보 | 텍스트로 자유 입력 (예: "강남역 근처", "6000만원 이상") |
| 평가 항목별 만족도 점수 | 0~100 사이 숫자 입력 |
| 메모 | 기타 특이사항 |

---

### 2-3. 가중 점수 자동 계산
- 각 항목의 `만족도 점수 × 가중치` 합산으로 **총점** 자동 계산
- 총점 기준으로 **순위(1순위, 2순위, 3순위...)** 자동 산출
- 목표 여부와 무관하게 전체 회사 랭킹 표시

**총점 계산 공식:**
```
총점 = Σ (만족도 점수_i × 가중치_i / 100)
```

---

### 2-4. 지원 프로세스 트래킹
각 회사의 진행 상황을 단계별로 관리:

```
지원 전 → 서류 지원 → 서류 합격 → 1차 면접 → 2차 면접 → 최종 합격 / 탈락
```

- 현재 단계 표시
- 단계 변경 시 날짜 자동 기록
- 탈락/합격 표시

---

### 2-5. 대시보드 (메인 화면)
- 전체 회사 목록 테이블 (스프레드시트 형태)
- 총점 기준 정렬 및 순위 표시
- 목표 회사 필터링
- 진행 상태 필터링
- 마감일 임박 회사 하이라이트

## 4. 기술 스택

| 영역 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | Next.js 14 (App Router) | 프로젝트명 기반, SSR/SSG 지원 |
| 언어 | TypeScript | 타입 안정성 |
| 스타일링 | Tailwind CSS | 빠른 UI 개발 |
| UI 컴포넌트 | shadcn/ui | 접근성, 커스터마이징 용이 |
| 데이터베이스 | SQLite (로컬) or Supabase (클라우드) | 개인 도구는 SQLite, 공유 필요 시 Supabase |
| ORM | Prisma | 타입 안전 DB 쿼리 |
| 상태관리 | Zustand or React Query | 서버 상태 동기화 |
| 배포 | Vercel | Next.js 최적화 |

## 5. 데이터 모델

### EvaluationCriteria (평가 기준)
```typescript
{
  id: string
  name: string        // 예: "복지"
  weight: number      // 예: 35 (합계 100)
  order: number       // 표시 순서
}
```

### Company (회사)
```typescript
{
  id: string
  name: string                    // 기업명
  isTarget: 'O' | 'X' | '△'     // 목표 회사 여부
  jobPostingUrl?: string          // 채용공고 링크
  recruitmentDeadline?: Date      // 채용 기한
  applicationStatus: ApplicationStatus
  memo?: string
  scores: CompanyScore[]
  createdAt: Date
  updatedAt: Date
}
```

### CompanyScore (회사별 점수)
```typescript
{
  id: string
  companyId: string
  criteriaId: string
  actualInfo: string    // 실제 정보 텍스트
  score: number         // 만족도 점수 (0-100)
}
```

### ApplicationStatus (지원 상태)
```typescript
enum ApplicationStatus {
  NOT_APPLIED = '지원 전',
  APPLIED = '서류 지원',
  DOCUMENT_PASS = '서류 합격',
  FIRST_INTERVIEW = '1차 면접',
  SECOND_INTERVIEW = '2차 면접',
  FINAL_ACCEPTED = '최종 합격',
  REJECTED = '탈락',
  WITHDRAWN = '지원 취소'
}
```

## 7. 핵심 UX 포인트

1. **스프레드시트 느낌의 테이블** - 한눈에 비교 가능
2. **인라인 편집** - 테이블에서 바로 점수 수정
3. **실시간 순위 업데이트** - 점수 변경 시 즉시 순위 반영
4. **마감일 D-day 표시** - 긴박함 시각화
5. **진행 상태 색상 구분** - 단계별 색상으로 빠른 파악
